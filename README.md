# Perceptron - Treino e avaliação

Este projeto foi desenvolvido utilizando o **VS Code**. 

**Importante para execução:** 
1. Ao abrir no VS Code, certifique-se de abrir o diretório/pasta completo do projeto, e não apenas o arquivo Python solto. Isso garante que o terminal seja iniciado no caminho correto.
2. Todos os arquivos `.csv` (bases de dados) devem estar salvos exatamente nessa mesma pasta junto com o código.
